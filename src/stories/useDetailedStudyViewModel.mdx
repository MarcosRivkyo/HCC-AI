# `useEstudioDetalleViewModel`

Este *custom hook* encapsula toda la lógica funcional y de interfaz para la vista de detalle de un estudio clínico en la plataforma **HCC-AI**.

---

## 🧩 Dependencias

Este hook hace uso de:

- `react-router-dom`: navegación y acceso a parámetros de ruta
- `firebase`: autenticación y Firestore
- `axios`: comunicación HTTP
- `jsPDF`, `html2canvas`: generación de documentos
- `marked`: parseo de markdown para explicaciones
- DAOs personalizados: `AuthDAO`, `UserDAO`, `StudyDAO`, `FileDAO`

---
